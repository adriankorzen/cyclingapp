# CyclingApp – frontend

Angular 22 web client of CyclingApp. See the [root README](../README.md) for how to run it together with the backend.

- `src/app/api` – API models and write operations (reads use `httpResource` in the pages)
- `src/app/rider` – currently selected rider
- `src/app/activities` – training log and activity detail pages
- `src/app/profile` – rider profile, threshold history and zones
- `src/app/shared` – formatting helpers and shared components
